================================================================================
  MUSOLLAH CONTENT TV — SETUP GUIDE (FROM SCRATCH)
  Raspberry Pi 4/5 + Raspberry Pi OS (64-bit)
  Repository: https://github.com/wanaideed/emosollah_tv
================================================================================


────────────────────────────────────────────────────────────────────────────────
HARDWARE REQUIRED
────────────────────────────────────────────────────────────────────────────────
- Raspberry Pi 4 (4GB RAM minimum) or Pi 5
- MicroSD card (16GB+, Class 10)
- HDMI display / TV
- Power supply (Pi 4: USB-C 5V 3A | Pi 5: USB-C 5V 5A)
- Internet connection (Ethernet recommended for first setup)
- Optional: USB speaker or 3.5mm speaker (for Selawat audio)


────────────────────────────────────────────────────────────────────────────────
STEP 1 — FLASH THE OS
────────────────────────────────────────────────────────────────────────────────
1. Download Raspberry Pi Imager: https://www.raspberrypi.com/software/
2. Insert SD card → Open Imager
3. Choose OS: Raspberry Pi OS (64-bit) — Desktop version
4. Click the gear icon (⚙) before flashing:
   - Set hostname:  musollah-tv
   - Enable SSH
   - Set username/password  (e.g. pi / yourpassword)
   - Set your WiFi credentials (or use Ethernet)
5. Flash → insert card → boot Pi


────────────────────────────────────────────────────────────────────────────────
STEP 2 — FIRST BOOT & UPDATE
────────────────────────────────────────────────────────────────────────────────
SSH in or use keyboard/monitor directly:

    sudo apt update && sudo apt upgrade -y
    sudo reboot


────────────────────────────────────────────────────────────────────────────────
STEP 3 — INSTALL SYSTEM DEPENDENCIES
────────────────────────────────────────────────────────────────────────────────
    sudo apt install -y \
        python3-pip \
        python3-venv \
        chromium-browser \
        unclutter \
        git \

────────────────────────────────────────────────────────────────────────────────
STEP 4 — CLONE PROJECT FROM GITHUB
────────────────────────────────────────────────────────────────────────────────
    git clone https://github.com/wanaideed/emosollah_tv.git ~/MusollahContentTV

Or copy from USB drive:
    cp -r /media/pi/USBDRIVE/MusollahContentTV ~/MusollahContentTV

STEP 5 — INSTALL PYTHON DEPENDENCIES
────────────────────────────────────────────────────────────────────────────────

        "zone": "SGR01",                                   ← * your JAKIM zone
        "musollah_name": "NAMA MUSOLLAH ANDA",             ← * your musollah name
        "template": "dark",                                ← dark | bright
        "enable_event_rotation": true,
        "enable_aktiviti_calendar": true,
        "enable_ticker": false,
        "enable_background_image": true,
        "page_rotation_seconds": 10,
        "masuk_duration_seconds": 30,
        "countdown_duration_seconds": 600,
        "jemaah_duration_seconds": 600,

────────────────────────────────────────────────────────────────────────────────
STEP 7 — SYNC PRAYER TIMES (FIRST TIME)
────────────────────────────────────────────────────────────────────────────────
Start Flask manually:

    cd ~/MusollahContentTV
    source venv/bin/activate
    python3 app.py &

Sync prayer times from JAKIM API (full year):

    curl http://localhost:5001/api/sync/prayer-times

You should see: "success": true, "days": 365 (or 366)

Stop Flask:

    kill %1

NOTE: Sync prayer times once a year (January) or whenever the zone changes.


────────────────────────────────────────────────────────────────────────────────
STEP 8 — UPDATE start_kiosk.sh FOR VENV
────────────────────────────────────────────────────────────────────────────────
    nano ~/MusollahContentTV/start_kiosk.sh

Change this line:
    python3 app.py &

To:
    /home/pi/MusollahContentTV/venv/bin/python3 app.py &

Make it executable:

    chmod +x ~/MusollahContentTV/start_kiosk.sh


────────────────────────────────────────────────────────────────────────────────
STEP 9 — AUTOSTART ON BOOT (SYSTEMD)
────────────────────────────────────────────────────────────────────────────────
Create the service file:

    sudo nano /etc/systemd/system/musollah-tv.service

Paste the following (replace "pi" with your actual username if different):

    [Unit]
    Description=Musollah Content TV
    After=network.target graphical-session.target
    Wants=graphical-session.target

    [Service]
    Type=simple
    User=pi
    WorkingDirectory=/home/pi/MusollahContentTV
    ExecStart=/bin/bash /home/pi/MusollahContentTV/start_kiosk.sh
    Restart=on-failure
    RestartSec=5
    Environment=DISPLAY=:0

    [Install]
    WantedBy=graphical-session.target

Enable and start:

    sudo systemctl daemon-reload
    sudo systemctl enable musollah-tv.service
    sudo systemctl start musollah-tv.service


────────────────────────────────────────────────────────────────────────────────
STEP 10 — DISABLE SCREEN SLEEP
────────────────────────────────────────────────────────────────────────────────
    sudo nano /etc/lightdm/lightdm.conf

Find the [Seat:*] section and add this line inside it:

    xserver-command=X -s 0 -dpms

Save and exit.

────────────────────────────────────────────────────────────────────────────────
WAKTU SOLAT SCREEN FLOW
────────────────────────────────────────────────────────────────────────────────
When a prayer time is reached, the kiosk automatically navigates to:
    /waktu_solat?solat={prayer_name}

3-Screen flow:

    ┌─────────────────────────────────────────────────────────────┐
    │  Screen 1 — WAKTU SOLAT [ASAR] TELAH MASUK                 │
    │             Countdown timer (masuk_duration_minutes)        │
    │             Selawat audio plays automatically               │
    ├─────────────────────────────────────────────────────────────┤
    │  Screen 2 — IQOMAH                                         │
    │             Countdown timer (iqomah_duration_minutes)       │
    │             Audio stops                                     │
    ├─────────────────────────────────────────────────────────────┤
    │  Screen 3 — Full-screen image                               │
    │             Shown for (solat_duration_minutes)              │
    │             Then redirects back to /                        │
    └─────────────────────────────────────────────────────────────┘

Prayers that trigger this flow: Subuh, Zohor, Asar, Maghrib, Isyak
Syuruk is DISPLAYED in the prayer table but does NOT trigger the flow.

Duration settings in settings.json:
    "masuk_duration_minutes":  1    ← Screen 1 countdown length
    "iqomah_duration_minutes": 10   ← Screen 2 countdown length
    "solat_duration_minutes":  20   ← Screen 3 display duration

────────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────
Problem: Browser does not open on boot
  → Check service logs: sudo journalctl -u musollah-tv.service -f
  → Make sure start_kiosk.sh uses full venv path for python3
  → Make sure start_kiosk.sh is executable: chmod +x start_kiosk.sh

Problem: Prayer times not showing (--:--)
  → Run: curl http://localhost:5001/api/sync/prayer-times
  → Check zone code in settings.json is correct
  → Make sure the Pi has internet access

Problem: Waktu solat screen does not auto-trigger
  → Prayer check runs every 10 seconds — wait up to 10s after prayer time
  → Confirm prayer data loaded: curl http://localhost:5001/api/prayer-times
  → Test manually: open http://localhost:5001/waktu_solat?solat=asar

Problem: Selawat audio does not play
  → Make sure selawat.mp3 exists in static/content/solat/
  → Check speaker is connected and volume is up
  → The Chromium flag --autoplay-policy=no-user-gesture-required is in start_kiosk.sh

Problem: Screen does not wake from sleep
  → Check /etc/lightdm/lightdm.conf has: xserver-command=X -s 0 -dpms
  → Also run: xset s off && xset -dpms && xset s noblank


────────────────────────────────────────────────────────────────────────────────
ANNUAL MAINTENANCE
────────────────────────────────────────────────────────────────────────────────
At the start of each new year, re-sync prayer times for the new year:

    curl http://localhost:5001/api/sync/prayer-times

This fetches all 12 months of prayer times from the JAKIM API
and overwrites the local data/prayer_times.json file.
